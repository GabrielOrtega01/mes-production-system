Objetivos del proyecto ACTIVIDAD SEMANA 2

Sistema de Control de Producción (MES) FábricaViva. Cada objetivo tiene un módulo funcional en esta página, conectado a una simulación de planta en tiempo real y a los patrones de software implementados en el código Java del repositorio.

1.Planifica órdenes en Planificación (ya hay 3 en cola).
2.Presiona Iniciar Turno en el panel derecho: las máquinas empiezan a producir.
3.Revisa equipos, calidad y OEE. Sube la velocidad a x20 para ver un turno completo.

OBJ 1Arquitectura del sistema

El MES está estructurado en capas y paquetes con una sola responsabilidad cada uno. Las capas superiores dependen de abstracciones de las inferiores, y cada paquete encapsula su patrón. Así la solución es modular, escalable y mantenible.

OBJ 3Control de calidad y trazabilidad

Cada orden genera un lote que pasa por el puesto de inspección: si la tasa de no conformes supera el umbral de la planta, el lote queda retenido. Todo el recorrido (material, máquina, protocolo, paradas, inspección y registro en ERP) queda en el historial.

OBJ 4Integración de máquinas CNC y robots

Simulación de la comunicación MES ↔ equipos. Cada familia de fabricante aporta su controlador y su sensor (Abstract Factory) y habla su propio protocolo: FANUC FOCAS2 y Siemens OPC-UA. El MES envía programas, lee telemetría, recibe fallas y reporta al ERP legado mediante un Adapter.

OBJ 5Eficiencia general de los equipos (OEE)

OEE = Disponibilidad × Rendimiento × Calidad, calculado con los tiempos y conteos reales de la simulación. El tiempo planificado es el tiempo que cada máquina tiene una orden asignada.

OBJ 7Escalabilidad y mantenibilidad

Incorporar nuevos dispositivos, procesos o funciones sin modificar los componentes existentes. Pruébalo: integra una familia nueva de robots o conecta equipos y mira cómo crece la capacidad de la planta.

Integrar un fabricante nuevo en caliente · Abstract Factory + OCP

Las familias de equipos se registran detrás de la interfaz FabricaEquipos. Agregar ABB es crear una clase nueva: el planificador, la calidad y el OEE la usan sin cambios.

Código de la extensión

equipos/abb/FabricaEquiposAbb.java
// Clase NUEVA — ninguna clase existente se modifica
public class FabricaEquiposAbb
    implements FabricaEquipos {
  public ControladorMaquina crearControlador() {
    return new ControladorAbbRws(); // REST
  }
  public SensorProduccion crearSensor() {
    return new SensorAbb();
  }
}
